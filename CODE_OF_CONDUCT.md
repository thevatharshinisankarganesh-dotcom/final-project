# Code of Conduct

## Our Pledge

We are committed to providing a welcoming, respectful, and inclusive environment for everyone participating in this project.

## Expected Behavior

Participants are expected to:

- Be respectful and professional.
- Communicate politely.
- Accept constructive feedback.
- Respect different opinions and experiences.
- Focus on improving the project collaboratively.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment or discrimination.
- Personal attacks.
- Offensive or inappropriate language.
- Sharing private information without permission.
- Any behavior that makes others feel unsafe or unwelcome.

## Reporting Issues

If you experience or observe inappropriate behavior, please report it to the project maintainer.

## Responsibility

Project contributors and maintainers are responsible for maintaining a respectful and welcoming environment.
